# Privacy Policy

furigana.it does not collect, store, or transmit any personal data.

All processing happens locally in your browser. Japanese text is tokenized
using a dictionary bundled with the extension — no text is ever sent to a
server.

The extension does not communicate with any remote servers and does not use
cookies, analytics, or tracking of any kind.

The source code is publicly available on GitHub for inspection.

## Permissions

- **Access to website content** — required to annotate Japanese text on pages
  where the user activates the extension. No page data is collected or
  transmitted.

- **Context menus** — required to add the right-click "Add furigana" option.
